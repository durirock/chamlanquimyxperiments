Hardware Philosophy

El Arduinator utiliza una topología de red distribuida donde la Raspberry Pi actúa como el orquestador de alto nivel (Host), mientras que los nodos Arduino Nano gestionan la periferia analógica en tiempo real. La comunicación se realiza vía **I2C Bus** para distancias cortas y **Serial UART** con aislamiento de ruido para el control de potencia.

Bus Volt: 12.8V DC
Logic: 3.3V/5V Hybrid
